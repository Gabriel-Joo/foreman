# 세션 화면 창

> 이 글은 세션 패널의 [세션 화면 ↗]로 여는 띄우는 창, 곧 세션의 실제 Claude Code 창을 브라우저 안에서 그대로 보고 키를 보내는 창을 다룹니다.

**세션 패널의 대화 탭은 Claude Code가 남긴 기록을 읽어 다시 그린 화면입니다. 세션 화면 창은 그와 달리 그 세션이 지금 떠 있는 Claude Code 창 자체를 브라우저에 띄웁니다. 권한을 묻는 창, 계획 승인 창, 선택지를 고르는 창처럼 기록에는 남지 않고 화면에만 떠 있는 것까지 보이고, 화살표, Esc, 숫자, Enter 같은 키를 보내 그 자리에서 답할 수 있습니다.**

![패널 위에 띄운 세션 화면 창입니다. 머리줄에 「세션 477 서기 — 포트폴리오 쓰기」와 「Claude Code 창 91×28」, [다시 붙기], [✕]가 있고, 창 안에는 그 세션의 Claude Code 화면이 그대로 보입니다. 창 뒤로 패널의 머리줄과 탭이 비칩니다 〔실제 화면〕](img/12_session_screen.png)

FOREMAN의 세션들은 서버의 tmux(터미널 하나를 여러 창으로 나눠 띄워 두는 프로그램) 안에서 돕니다. 세션 패널은 Claude Code가 파일로 남기는 대화 기록을 읽어 대화와 활동을 보여 주지만(→ 「세션 패널: 대화와 활동」), Claude Code가 화면에만 잠깐 띄우는 창은 기록에 없어서 패널로는 볼 수 없습니다. 예를 들어 세션이 auto mode 밖의 권한을 묻거나, 계획을 승인해 달라고 하거나, 여러 선택지 중 하나를 고르라고 하면 세션은 그 창에서 사람을 기다리며 멈춥니다. 세션 화면 창은 그 순간 그 세션의 진짜 화면을 보여 주고, 사람이 키를 눌러 그 창을 닫거나 고르게 합니다. 서버에 원격 데스크톱으로 들어가 터미널을 찾지 않아도 됩니다 [code:bridge/static/js/ccscreen.js] [log:coder_ccscreen_20261114.md].

## 여는 법과 붙는 곳

세션 패널 탭 줄 오른쪽 끝의 [세션 화면 ↗]를 누르면 패널 위에 창이 뜹니다. 화면을 덮는 확인 창(모달)이 아니라 떠 있는 창이라, 열어 둔 채로 패널의 대화 탭을 함께 읽을 수 있습니다. 머리줄에는 세션 번호와 제목이 붙고, 열어 둔 채 패널에서 다른 세션을 골라도 창은 처음 띄운 세션을 계속 보여 줍니다. 띄운 세션과 패널에서 고른 세션이 다르면 머리줄에 「세션 N로」 단추가 생겨, 누르면 창이 그 세션으로 바뀝니다. 창은 하나만 띄웁니다 [code:bridge/static/js/ccscreen.js] [log:coder_ccwindow_20261114.md].

브라우저는 세션 번호만 보냅니다. 어느 tmux 창에 붙을지는 브리지(FOREMAN의 서버 프로그램)가 정합니다. 브리지는 그 번호가 데이터베이스에 있는 Claude Code 세션인지, 그 세션의 프로세스가 지금 살아 있는지, FOREMAN이 쓰는 tmux 안에서 도는지, 그 tmux 창의 프로그램이 정말 그 세션의 Claude Code인지를 차례로 확인하고 나서야 붙입니다. 하나라도 맞지 않으면 창 안에 까닭을 「~습니다」로 적습니다. 세션이 끝났으면 「세션이 끝나 세션 화면을 열 수 없습니다」, 사람이 Ctrl+Z로 멈춰 둔 세션이면 일부러 멈춰 둔 것이라 열지 않는다고 알립니다. 창이 열려 있는 동안 5초마다 다시 확인하고, 브리지를 다시 띄워 연결이 끊긴 채 남았으면 [다시 붙기]로 다시 붙습니다 [code:bridge/terminal.py] [code:bridge/api/terminal.py].

창 안의 화면은 셸과 같은 틀을 하나 더 띄운 것입니다(→ 「셸 패널」). ttyd라는 작은 프로그램이 tmux 창을 브라우저에서 쓰는 터미널 화면으로 내보내고, 브리지가 로그인 쿠키와 같은 사이트에서 온 요청인지를 확인한 뒤에만 그 화면을 브라우저에 이어 줍니다. 붙을 때는 그 세션의 tmux에 이 창 몫의 묶음(같은 창을 함께 보는 그룹 세션)을 따로 만들어 붙으므로, 창을 닫아도 Claude Code 세션 자체는 그대로 남고 보던 묶음만 사라집니다. 열고 닫은 시각과 대상은 세션 기록에 남기지만, 친 키 하나하나는 남기지 않습니다(→ 「알려진 한계」) [code:deploy/shell/foreman-cc-view] [code:bridge/api/terminal.py].

## 창 옮기기와 크기

머리줄을 끌면 창이 옮겨지고, 네 모서리 중 아무 곳이나 끌면 크기가 바뀝니다. 크기는 끄는 동안에는 테두리만 따라 움직이고, 손을 놓을 때 한 번만 적용됩니다. 창 크기를 바꾸면 그 안의 Claude Code 창도 같은 크기로 맞춰지기 때문입니다. 끄는 동안 계속 맞추면 Claude Code 화면이 매번 다시 그려지며 흔들립니다. 머리줄의 「Claude Code 창 91×28」은 지금 Claude Code 창의 가로 글자 수와 세로 줄 수이고, 모서리를 놓자마자 새 숫자로 바뀝니다 [code:bridge/static/js/ccscreen.js] [c:fcd4b68] [c:3d34db3].

정한 자리와 크기는 이 브라우저에 기억해 두었다가 다음에 열 때 같은 크기로 엽니다. 크기를 한 번 정해 두면 Claude Code 창이 흔들리는 것은 열 때 한 번뿐입니다. 창이 브라우저 화면 밖으로 나가 다시 잡을 수 없게 되지 않도록, 머리줄 일부는 늘 화면 안에 남깁니다. 창을 닫으면 Claude Code 창은 쉴 때 크기인 80×24로 돌아갑니다. 같은 세션을 두 사람(두 탭)이 동시에 보면 나중에 붙은 쪽 크기를 따르고, 한쪽이 닫으면 남은 쪽 크기로 다시 맞춥니다. 사람이 tmux에서 직접 창 크기 규칙을 정해 둔 창이면 크기는 건드리지 않고 보기만 합니다 [code:deploy/shell/foreman-cc-view] [code:bridge/terminal.py].

## 보낼 수 있는 키

창 안을 누르면 키보드 입력이 그 Claude Code 창으로 그대로 갑니다. 이 창을 만든 목적은 화면에 떠 있는 결정 창에 답하는 것이라, 쓰임새는 주로 화살표로 선택지를 옮기고, 숫자로 번호를 고르고, Enter로 정하고, Esc로 닫는 것입니다. 키에 제한을 두지는 않았습니다(→ 「알려진 한계」). 다만 FOREMAN의 다른 기능이 같은 세션에 글을 넣으려 할 때, 사람이 이 창에서 치다 만 글이 입력 칸에 남아 있으면 그 글을 덮어쓰지 않고 넣지 않은 채 알립니다. 사람의 손과 자동 입력이 한 입력 칸에서 섞이지 않게 하는 장치입니다 [code:bridge/static/js/ccscreen.js] [code:bridge/inject.py].

승인 카드가 뜬 명령은 화면 카드와 Claude Code 창의 승인 창 중 먼저 답한 쪽이 정합니다(→ 「승인 카드」). 세션 화면 창은 그 Claude Code 창을 브라우저에서 보는 길이므로, 카드가 닫힌 뒤에도 승인 창이 남아 있으면 여기서 답할 수 있습니다.
