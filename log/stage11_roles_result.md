## '푸른 고래' 요약이 다시 보인 것

- 지운 시험 요약(1번)은 DB에 없었다. 보인 것은 **2번** — 세션 177(소품 · 이름표 작업)이 06:41에 쓴 진짜 요약이다
  - 177의 제목은 CC 자동 제목 "푸른 고래 인계 시험"이었다. 177이 처음 떴을 때 첫 입력이 시험 요약이었기 때문이다
  - 고르는 칸이 요약을 세션 제목으로만 보여 줘서 옛 요약으로 보였다
  - 캐시 · 브라우저 · 코드 문제는 아니었다
- 요약 0개면 끄는 코드는 맞았다. 다만 **모든 프로젝트의 요약을 세서** 다른 프로젝트 요약 하나로도 켜졌다
- 고친 것
  - 고른 프로젝트(떠돌이는 프로젝트 없는 것)의 요약만 센다
  - 칸에 세션 번호 · 시각 · 본문 첫 줄을 보인다(API `head`). 포먼 계획 카드도 같게 했다
  - 177의 이름을 "소품 놓기 · 이름표 자리 · 인계 요약 고르기"로 바꿨다(패널 이름 바꾸기, 비우면 되돌아간다)
- 확인(헤드리스)
  - 포먼: 칸 켜짐, 2번이 본문 첫 줄과 함께 보였다
  - 런슈즈: 칸 꺼짐, "넣을 요약이 없습니다"
