# 글씨 키우기 · 사람이 붙인 세션 이름이 항상 이기게 (2026-11-06)

## 1. 세션 이름이 "자동 제목으로 돌아간다"

조사:
- **DB에 남아 있다.** `character_session.custom_title` 21개. 같은 세션 안에서 지워진 적은 없다
- **CC가 대화 중에 다시 짓는 제목(ai-title, 12,053줄)은 `title` 칸만 고친다**(`bridge/assembler.py` ai-title). `custom_title`은 건드리지 않는다. CC 안의 `/rename`(custom-title 레코드)은 한 번도 쓰이지 않았다
- **주 화면(캐릭터 이름 · 패널 제목 · 툴팁)은 사람 이름을 먼저 쓴다**(`render.js sessionName`, `office.js` 이름)
- 돌아간 것처럼 보인 까닭 두 가지:
  1. **세션이 바뀌면 행이 새로 생긴다.** 인계 · 정전 뒤 새로 띄운 세션은 새 `character_session` 행이라 이름이 없다(예: 189「FOREMAN 인계」→ 정전 뒤 197은 새 세션, 자동 제목). 인계로 띄울 때 이름 칸을 비우면 원 세션 이름을 물려받지 않았다
  2. **자동 제목만 쓰던 화면이 있었다** — 터미널 목록(`terminal.py`), 커밋 알림 · 출하 라인 커밋 목록(`pipeline.py` 세 곳), 인계의 원 세션 표시(`handoff.py`)

고친 것:
- 위 다섯 곳을 `COALESCE(custom_title, title)`로
- 인계 요약으로 새 세션을 띄울 때 이름을 따로 주지 않으면 원 세션의 사람 이름을 물려받는다(`HandoffManager._inherited_title`). 이름을 주면 그것이 이긴다. 그냥 [+ 세션]으로 띄운 새 세션은 물려받지 않는다
- 시험: `test_custom_title_survives_ai_title_and_passes_to_handoff`(ai-title 두 번 뒤에도 사람 이름 그대로, 인계 승계)
