# docs의 화면 글 인용을 지금 화면과 맞춤 (2026-11-15, 세션 foreman-5 · `cc/foreman-5`)

관리자 410 서기 일감(사용자 지시 11-15: 「문서는 서기에게 맡겨 화면 글과 맞춰라. 사람 승인 카드는 내게 올려라. 가운뎃점은 그대로 둔다. 확인 창 약속만 지금처럼 유지한다.」). 11-15에 화면 글의 em dash를 없앴다(화면 코드 `945b3a7` · `log/foreman-3_screen_emdash_20261115.md`, 서버 글 `c2fbae6` · `log/foreman-4_server_emdash_20261115.md`). 그 두 세션이 건드리지 않은 `docs/style_guide.md` · `docs/operations.md`와 같은 꼴의 낡은 인용이 남은 다른 docs를 코드의 지금 문자열과 맞댔다. 코드는 고치지 않았다.

## 찾았지만 둔 곳

- 툴팁 첫 줄 「제목 — 설명」(예: `style_guide.md` 90 · 127 · 132 · 139의 첫 줄, `10_office_design.md` 114 · 127 · 135 · 151~155 · 197 · 287, `11_worktree.md` 120 · 121, `15_usage.md` 87, `13_demo_capture.md` 97): 지금 화면에도 있다
- 코드가 자르는 기호가 든 글: 끝난 까닭 「쉬게 했습니다 — 합치기 기다림」, 교장 노트 `wake_text`, 서기 이름 「서기 — …」, 쉬게 하기 커밋 제목 「쉬게 하기: 진행 중 저장 — <제목>」(`11_worktree.md` 125, `handoff.py` 1328), 「다른 저장소 쓰기 막힘 — …」(`11_worktree.md` 215, 세션에 가는 PreToolUse 거부 사유 `reposcope.py` 408)
- 텔레그램 글과 세션에 넣는 글 인용: `operations.md` 111(「같은 파일 — 세션 A와…」, `overlap.py` 251) · 120 · 121 · 122(권한 거부 · API 오류 · `!` 알림), `11_handoff_v2.md` 119 · 124(텔레그램 `compactwatch` · `switchwatch`), `11_worktree.md` 193 · 194(텔레그램 `mergeprep.py` 766), 로그 글 「스키마 잠금을 일찍 풀었다 — …」(`main.py` 306 `log.info`)
- 지운 기능이나 옛 글을 이력으로 적은 곳: `style_guide.md` 89(「이 세션의 모델 — /model을 보냅니다」), 88 · 121, `15_usage.md` 65 · 85(지운 「추가 사용」 칩)

- `11_worktree.md` 122 「세션을 끝내면서 합치거나 버립니다 — …」, `11_foreman_dispatch.md` 91 「이렇게 보자고 합니다 — [시작]」은 코드에서 같은 문자열을 찾지 못해(지금 화면과 대지 못해) 두었다
