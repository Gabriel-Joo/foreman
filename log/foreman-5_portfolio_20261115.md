## 관찰 (고치지 않음, 관리자가 볼 것)

- 화면 말 시험이 `[code:]`를 버튼으로 읽던 것: 관리자가 main `e5d584b`에서 고쳤다. 이 브랜치를 main 위로 옮겨 다시 돌렸다
- 출하 라인: Jenkins가 빌드·push가 아닌 단계(예: Test)에서 실패하면 Harbor 이름표가 ✓로 그려진다(`bridge/static/js/office.js` INFRA_STAGES 근처). 이미지가 안 올라갔는데 ✓면 틀린 표시다
- [⌂] 교장 패널 맨 아래에 「진행 중인 일을 읽지 못했습니다」가 떠 있다. 라운지 노트를 못 읽는 것으로 보이나 원인은 보지 않았다
- [⌂] 교장 패널에는 모든 프로젝트의 진행 글이 나온다(펫퍼민트 글이 보여 사진은 FOREMAN 방 것으로 씀)
- `config/wake.toml`의 `public_url`은 지금 `http://localhost:8000`이다. 목차 기록 「확인하지 못한 것」의 외부 주소 이야기는 낡았다. 휴대폰에서 [시작] 링크가 열리는지는 보지 않았다
- `office.js`의 한 주석은 「⚠ 사용량」인데 실제 글은 「⚠ 한도」다
- 세션 화면 창을 찍느라 이 세션(477)의 Claude Code 창 크기가 91×28로 바뀌었다가 닫으며 80×24로 돌아갔다(두 번)
