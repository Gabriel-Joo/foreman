# 다른 프로젝트 같은 글 알림 · 시험이 운영 점검을 죽이던 것 (2026-11-09 밤)

사용자가 자는 동안 할 일로 정했다: ① 펫퍼민트 압축 손실 점검(세션 155, 11-08 사용량 때문에 미룬 것 — 리셋으로 1%) ② 다른 프로젝트 세션에 이미 들어간 글 알리기(11-08 신발 지시가 FOREMAN 세션에 들어온 일).

## 1. 다른 프로젝트 같은 글 (`bridge/overlap.py`, `js/opanel.js`)

- 사람 글이 들어오면 **다른 프로젝트**의 살아 있는 세션이 최근(180분) 받은 사람 글과 맞댄다 — 낱말 집합(한글 포함) 자카드 ≥ 0.8, 양쪽 낱말 12개 이상(`same_text`). 걸리면 텔레그램 + 패널 띠 「📋 다른 프로젝트 — 이 글은 런슈즈 세션 217에 14:14에 들어간 글과 거의 같습니다. 잘못된 창에 붙여 넣었을 수 있습니다」, 작업 중이면 **[이 세션 작업 중단]**(Esc)
- 막지 않는다(같은 지시를 일부러 두 프로젝트에 줄 수 있다). 같은 두 세션은 한 시간에 한 번
- 지난 7일 다시 돌리기(사람 글 429개): 9쌍 — 11-08 신발 지시 3(214 ↔ 200 · 217) · 「적재하고 다시 검사해라」(200 ↔ 211) · 11-01 ~ 11-05 넷. 모두 같은 붙여넣기 글이 두 프로젝트에 그대로 들어간 것 — 헛알림으로 볼 것은 없었다. **잘못 붙여 넣기가 한 주에 여러 번 있었다**
- 시험: 실제 신발 지시로 판정(꼬리표 id만 다름 · 한 줄 덧붙임 · 짧은 글 제외 · 다른 글) · 가짜 DB로 알림(끝난 세션은 안 봄)

## 2. 시험이 운영 브리지의 점검을 "실패"로 바꾸던 것

- 점검 #2(세션 155)를 00:07에 시작 → 00:09 "브리지가 다시 떠서 멈췄습니다"로 failed. 브리지는 00:05부터 다시 뜬 적이 없었다(NRestarts 0)
- 원인: `tests/test_app_db.py`는 운영 DB에 대고 앱을 띄운다. 앱은 뜰 때 `LossChecker.recover()`로 running 점검을 모두 failed로 바꾼다 → **시험을 돌리기만 해도 운영에서 도는 점검이 실패로 적혔다**(작업 자체는 운영 브리지에서 계속 돌았다 — 화면엔 실패, 같은 점검을 또 시작할 수 있음)
- 고침: 설정 `losscheck_recover`(기본 켬), `test_app_db`는 끈다. 앱이 뜰 때 운영 DB를 고치는 정리는 이것 하나뿐이었다(main.py 확인)
- #2는 running으로 되돌렸다(내 시험이 바꾼 것). 고친 뒤 전체 시험 475를 다시 돌려도 #2는 running으로 남았다

- 점검 #2(세션 155) 끝 — 프롬프트 151 · 묶음 12 · $3.61. 사라짐 93 · 약해짐 38 · 뒤집힘 16 · 살아 있음 42 · 끝남 81. 사라진 것은 주로 어댑터 비교 조건 · na_judge 판정기 조건 · 재구축 순서 같은 작업 결정(펫퍼민트 저장소는 건드리지 않음). 기계 점검이 처음으로 끝까지 돌았다
- 화면 말: "인계" → "새 세션으로 옮기기"(버튼 · 띠 · 확인 창 · 거부 사유 · 텔레그램). 세션에 넣는 글(`[FOREMAN 인계 …]`)과 docs · log는 그대로. 「인계 작업 중입니다」는 제목 "인계" 옆에 서버 why("작업 중입니다")가 붙은 것 — 제목은 "새 세션으로 옮기기", 사유는 버튼 아래 회색("세션이 작업 중이라 지금은 못 합니다. 끝나면 눌러주세요.")
- 맥락 띠: 「🧠 지금까지 쌓인 대화 336k · 응답당 약 $0.07」, 호버 「토큰 33만 6천, 한글 30만 자, 책 세 권쯤 …」. 응답당은 대시보드가 사용량 설정의 캐시 읽기 가격으로 더한다(`usd_reply`)
- "▶ 턴 나 · 10분 전 시작" → "▶ 작업 중 · 10분째"(무엇으로 시작했는지는 호버), "끝 신호 없는 턴" → "끝났는지 모름". 사용량 칩 "5h · 주 · ~" → "5시간 · 주간 · 약", 승인 이력 → 승인 기록(모름 → 답 확인 못 함, 늘 Yes → 늘 허락함)
- 툴팁 겹침: `tip.js`는 마우스를 올린 순간에만 title을 data-tip으로 옮겼다 — 다시 그리며 title을 또 붙이는 곳(머리말 작업 수 등)에서 기본 툴팁과 둘이 떴다. MutationObserver로 title이 붙는 순간 옮긴다(꺼진 버튼은 이벤트가 안 와 기본 툴팁 하나로 둔다). 세 테마 화면에서 남은 title 0
