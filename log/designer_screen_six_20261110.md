## 1. 질문 카드 — 답한 뒤 자리 · 답하면서 글도 보내기 (받은 할 일 #2)

한 일
- 답하면 카드가 한 줄 "✓ 답함 — 「질문」 → 고른 답 · 글: …"로 접힌다(누르면 펼침, 줄 끝 [×] 치우기). 30초 자동 지우기는 없앴다 — 세션마다 최근 3줄만 남긴다(`store.js FOLD_KEEP`). 접힌 줄은 그 세션 패널에만 보인다
- 답이 줄에 보이게 브리지가 처리 끝(resolved) 알림에 `message`(고른 답 · 글)와 `decided_by`를 싣는다(`approvals.py`). 이 화면에서 답했으면 화면이 기억한 답, 터미널에서 답했으면 "터미널에서 답함"
- 치운 뒤 다시 보기: 「세션」 탭 승인 기록에 질문 줄은 "답함 … → 고른 답"과 세션 번호를 보인다(`/api/approvals/history` 항목에 `message` · `session_id`). DB `approval.message`에 답이 남는 것을 확인(#84 · #87 — "질문 → 답" 모양). 칸이 255자라 긴 질문 뒤의 답이 잘릴 수 있어, 기록할 때 질문을 80자로 먼저 줄인다
- 글 칸: 선택지 아래 "답과 함께 보낼 글". 고르면 글도 같이 간다, [글만 보내기]는 고르지 않고 글만. 브리지는 글을 첫 질문의 `annotations[질문].notes`로 넘기고, 고르지 않은 질문은 `"(notes only)"`로 둔다(`POST /api/approvals/{id}/answer`에 `note`)
- 승인 카드(🔐)도 같은 규칙 — 처리하면 "✓ 허용함 / ✕ 거부함 — ▶ 요약" 한 줄로 접힌다
- 이 세션이 질문의 답을 기다리는 동안 패널 입력 칸은 한 줄 안내("질문에 답하는 중 — 글은 질문 카드의 글 칸으로 · 입력 칸 펼치기")로 접는다

판단 근거
- 글을 넘기는 자리: 설치된 CC(2.x) 실행 파일에서 AskUserQuestion 결과 만들기를 읽었다 — `annotations[q].notes`가 있으면 모델에게 `"질문"="답" notes: 글`로, 답이 `"(notes only)"`면 `"질문"=(no option selected) notes: 글`로 간다. 훅 `updatedInput`도 `annotations`를 받는다(허용 키 목록 `answers · annotations · response · followUp`). 그래서 답 문자열에 글을 이어 붙이지 않고 CC가 정한 자리에 넣었다
- 승인 카드도 접은 까닭: 처리된 승인도 같은 자리(대화 칸 위)를 먹고, 한 줄에 허용/거부와 무엇을 했는지가 다 보인다
- 입력 칸 접기: 1366 · 125%에서 질문 카드 · 띠 둘 · 입력 칸을 다 담을 높이가 없어 카드가 입력 칸 밑에 묻혔다. 카드에 글 칸이 있으니 그동안은 카드에 자리를 준다

확인 — 답 전후 `pAppr` 높이(세 테마 같음, 장면: 이 세션 질문 1 + 다른 세션 승인 · 질문 2): 1920 389 → 128px · 1366 249 → 123px · 1024 194 → 52px. 대화 칸은 1920에서 30 → 92px(1366 · 1024는 띠 · 머리줄이 다 먹어 30px 그대로 — 아래 「남은 것」)
