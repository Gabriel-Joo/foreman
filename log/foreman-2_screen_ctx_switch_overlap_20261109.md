### 바꾼 것

- **낱말 겹침(사람 요청 때)**: 텔레그램을 보내지 않는다. 패널 띠만, 그리고 상대가 겹친 낱말의 파일을 실제로 고쳤는지 근거를 붙인다(`edited` — 있으면 노랑 "실제로 고쳤습니다", 없으면 `weak` 옅은 띠 "말에 나왔을 뿐일 수 있습니다")
- **같은 파일(새로 넣음)**: `OverlapWatch.scan_files` — 60초마다(`edit_scan_sec`) 같은 프로젝트의 살아 있는(멈춘 T 아님) 두 세션이 최근 `window_min`(180분) 안에 같은 파일을 Edit · Write · NotebookEdit · MultiEdit 했나. 텔레그램 `kind='overlap'` "같은 파일 — 세션 A와 세션 B가 둘 다 고쳤습니다: …" + 두 세션 모두 패널 📝 띠. **새로 겹친 파일이 생길 때만** 다시 알린다
  - 경로는 저장소 기준으로 맞춘다(`rel_path`) — `.worktrees/<이름>/bridge/x.py`와 원본 `bridge/x.py`를 같은 파일로 센다. 세션 폴더 밖(메모리 · scratchpad · 다른 저장소)은 보지 않는다
  - 인계로 이어진 두 세션은 뺀다(넘겨받아 이어 고치는 것). 서브에이전트가 고친 것도 그 세션 것으로 센다
  - 훑기는 첫 사람 입력 때 띄운다(`start_scan`) — `main.py`를 고치지 않으려고
- **다른 프로젝트에 같은 글(📋)**은 그대로 텔레그램
