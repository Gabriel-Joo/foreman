## 기록과 코드가 달랐던 점(코드대로 씀)

- **임시 일꾼 이름표**: `coder_resident_20261109.md`는 "임시 · <세션 제목>", 코드(`office.js` `roleName`)는 `[코더] 임시` — 242가 「이름표는 역할만」으로 바꾼 뒤다. docs에는 지금 것을 쓰고 옛 모양은 바뀐 까닭과 함께 적었다
- **받는 함 "3일 알림"**(지시문 낱말): 텔레그램이 아니라 서기 할 일 글에 "가장 오래된 것 N일째"를 붙이는 것이다(`scribe_room.py` `INBOX_STALE_DAYS = 3`). docs에 "텔레그램은 보내지 않는다"고 적었다
- **합치기**: 옛 CLAUDE.md는 "사용자가 패널 [합치기]"뿐. 코드에는 패널 길 둘(「따로 작업」 [합치기], 「세션」 [끝내고 합치기] = `end: true`)이 그대로 있고, 관리자는 같은 API를 부른다. `git merge-tree` 확인은 코드에 없는 **약속**이다 — docs에 그렇게 적었다
- **`/api/spawn`을 관리자가 쓰지 않는다**도 약속이다 — 코드는 막지 않고, `/api/spawn`은 `dispatch`를 남기지 않는다(그래서 README 「교장 ④」가 남은 일)
- **[쉬게 하기] 막는 조건**: 기록은 "작업 중 · 뒤에서 도는 일", 코드도 둘을 따로 막는다(`busy` → "작업 중입니다", 뒤 일 → 개수와 까닭). 같다
- **[계획으로] 할 일을 이미 다른 세션이 가져갔을 때**: 기록에 없던 것 — 코드(`foreman.py` `start`)는 시작을 막지 않고 그 세션 몫으로 적지만 않는다. docs에 적었다
