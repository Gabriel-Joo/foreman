# 입력 칸 높이 띠 — 끄는 동안 쪽지 끄기 · 끌고 나면 맨 아래 붙이기 (2026-11-11, worktree foreman-3, 디자이너)

브랜치 `cc/foreman-3`, push 안 함. 고친 파일은 `bridge/static/js/opanel.js` 하나(CSS · 시험 파일은 건드리지 않음).

## 한 일
### 하나 — 끄는 동안 쪽지가 꺼진다
- **원인**: 띠의 `pointerdown`이 `preventDefault()`를 부른다(글자 선택 막기). 그러면 `mousedown` 호환 이벤트가 오지 않아, `tip.js`의 「mousedown이면 쪽지 숨김」이 돌지 않았다
- **고침**: 끌기 시작에 `hideTip()`을 부르고 띠의 `data-tip`을 잠깐 떼어 둔다(끄는 동안 마우스가 띠에 있어도 다시 뜨지 않는다). 놓으면 되돌린다 — 다시 올리면 뜬다
- `tip.js`는 고치지 않았다(맡은 파일 밖)

### 둘 — 끌고 나면 맨 아래에 붙는다
- **원인**: 대화 칸 높이가 바뀔 때 「아래쪽 거리」(소수점 px)를 그대로 지켜서, 글씨 배율(zoom)로 `scrollTop`이 소수일 때 한 번 맞출 때마다 0.2~0.4px씩 어긋났고 그 값이 다시 기억되어 쌓였다. 마지막 높이 변화 뒤 한 번 더 붙이는 곳도 없었다
- **고침**: 「맨 아래를 보고 있었는가」(`convoStick`, 아래쪽 거리 4px 미만)를 따로 기억한다. 맨 아래였으면 높이가 바뀔 때마다 `scrollTop = scrollHeight`로 붙이고, 아니면 보던 자리(아래쪽 거리)를 지킨다. 끌기를 마친 뒤에도 두 프레임에 걸쳐 한 번씩 더 붙인다(`repinConvo`)
- 쪽지 · 띠 높이 때문에 어긋난 것은 아니었다 — 쪽지는 문서 흐름 밖이고, 띠는 입력 칸 안이라 대화 칸 높이 계산에 이미 들어 있다

## 지킨 것 · 어긴 것
- 시험 파일은 새로 쓰지 못했다 — `opanel.js`는 DOM이 있어야 읽혀 node 시험으로 부를 수 없고, 순수 함수로 빼면 맡은 파일 밖이 늘어난다. 대신 위 헤드리스 점검으로 대신했다(스크립트는 세션 임시 폴더, 저장소에 두지 않음)
