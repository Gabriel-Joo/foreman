## 2. 합친 뒤 초록 글: 짧은 새 글 하나만

같은 말이 세 군데에서 나왔다:
1. `mergedNote` 위 두 줄(「main에 커밋 8개를 하나로 합쳤습니다. push는 아직입니다.」 + 「해시 「제목」」) — **남김**
2. [합치기]를 누른 뒤 결과 글 — `run('합치기 승인', …)`이 서버 응답 `r.note`(옛 긴 글)를 패널 결과 칸(`note`)에 그렸다. 응답의 `card`로 `mergedNote(r.card)`가 그려지면 `{ quiet: true }`를 돌려 결과 글을 띄우지 않게 했다(`run`이 `quiet`면 `note = null`). 갈래(`merge_result`)가 없는 옛 응답이거나 실패면 전처럼 `r.note`
3. 「자세히」 안 「합치기 결과 원문: …」 — **뺐다**

「자세히」 안에는 squash 설명과 `git log refs/foreman/squashed/…` 명령만 둔다. 「관리자 세션에 알렸습니다」 · 「시험, push, 브리지 다시 띄우기는 관리자가 합니다」 줄도 뺐다(뒤 줄은 [합치기] 호버에 같은 말이 있다).

- **판단**: 관리자 세션에 **못** 알렸을 때(`manager_told === false`)의 「관리자 세션에는 알리지 못했습니다(텔레그램으로 남김).」은 「자세히」 안에 노랑(`warn`)으로 남겼다. 브리프의 「squash 설명과 명령만」보다 하나 더지만, 지우면 관리자에게 안 간 것이 화면에서 조용히 사라진다(CLAUDE.md 맨 위 「조용한 고장」)
- **옛 카드 대체**: `merge_result`가 없는 합친 카드는 전처럼 카드 아래 `note` 원문을 그린다(그대로 둔 대체, `mergedNote`가 `null`일 때만)
- 작업방 칸 [합치기] · [끝내고 합치기](`wt-merge` · `wt-end-merge`, 합치기 카드가 아닌 길)는 결과 글이 `r.note` 하나뿐이라 겹치지 않아 그대로 두었다
- 관리자 입력 칸에 가는 「[FOREMAN 합치기] …」 글과 서버 `note`는 그대로다

## 3. 「자세히」 안 정리

- 「합치는 방법: 충돌 없음 · ff 가능」 → **「합치는 방법: 충돌 없음」**. 호버도 「충돌 없음 — 합칠 때 같은 줄을 서로 고친 곳이 없습니다.」로. rebase 쪽 「충돌 없음 · main에 새 커밋 N개(rebase)」는 가운뎃점만 쉼표로(「충돌 없음, main에 새 커밋 N개(rebase)」)
- 같은 까닭으로 「ff」를 말하던 호버 둘도 고쳤다: 위 줄 「충돌 없음」 호버 「ff · rebase 여부는 「자세히」에 있습니다」 → 「main이 앞섰는지는 「자세히」에 있습니다」, 「자세히」 호버 「합치는 방법(ff · rebase), … 커밋 · 바뀐 파일, …」 → 「합치는 방법, …, 커밋과 바뀐 파일, …」
- 「사람에게 올린 까닭: 늘 사람 경로(…): a/V22…, …」 → 이 꼴:
  ```
  늘 사람이 승인해야 하는 파일입니다.
    V22__review_hide.sql
    V23__chatbot_miss_status.sql
  ```
  파일은 `humanFiles(c)`로 뽑고(새로 파싱하지 않음), 줄은 위 「승인해야 할 파일」과 같은 `.mp-hf-row`(들여 씀 · 고정폭)로, 호버는 전체 경로. 늘 사람 경로가 아닌 까닭(지우기 · 자원 크기 · 서브모듈)의 파일은 그 까닭 글(서버 글)을 머리로 같은 꼴, 파일이 없는 까닭(이력 다시 쓰기 등)은 까닭 글 한 줄 그대로
  - **서버 글이라 그대로 둔 것**: 그 까닭 글들에 가운뎃점이 보일 수 있다(예: 「이력 다시 쓰기 · force push(커밋 글에 「…」)」, 「자원 크기(a · b)」). `bridge/mergeprep.py` `human_reasons` 글이라 이번 일 밖이다. ready 카드의 서버 `note`(「사람 승인 카드입니다 — … 늘 사람 경로(…): …」)도 서버 글이라 그대로 — 「자세히」 안에 「늘 사람 경로」 말이 이 note로는 아직 보인다
  - **겹침**: 카드 위쪽 「승인해야 할 파일 N개」와 같은 파일 이름이 「자세히」 안에 한 번 더 보인다. 사용자 꼴대로 두었다
  - 위쪽 「승인해야 할 파일」 줄 호버도 「경로 — 늘 사람 경로(패턴)」에서 **경로만**으로 바꿨다(「늘 사람 경로」 말을 쓰지 않는다는 사용자 말을 따름). 늘 사람 경로가 아닌 까닭이면 「경로 — 까닭」 그대로
