## 한 일

카드 위쪽에 이미 보이는 말이 「자세히」 안에 또 있던 것을 뺐다.

- 「합치는 방법:」 머리말과 「충돌 없음」을 뺐다. main이 앞선 카드만 「main에 새 커밋 N개(rebase)」 한 줄이 남는다(ff 카드와 충돌 카드는 그 줄이 없다. 충돌 카드는 위에 「충돌 N개」 · 「충돌 파일」이 이미 있다)
- 「늘 사람이 승인해야 하는 파일입니다.」와 그 아래 파일 줄을 뺐다. 위 「승인해야 할 파일 N개」가 같은 말이다
  - 위에 안 보이는 것은 남겼다: 늘 사람 경로가 아닌 까닭(지우기 · 자원 크기 등)은 까닭 글을 머리로 파일 줄과 함께(위에는 그 까닭이 호버에만 있다), 파일 없는 까닭(이력 다시 쓰기 · 판정 실패 등)은 위에서 60자로 잘렸을 때만 전부
- 서버 `note`의 「사람 승인 카드입니다 …」 · 「관리자가 승인합니다 …」와 「관리자 세션에 알렸습니다」를 뺐다. **알리지 못한 것(`manager_told === false`)은 경고(`warn`)로 남겼다**(서버 note가 「알리지 못해 …」면 그 글이 경고색으로, 아니면 「관리자 세션에는 알리지 못했습니다(텔레그램으로 남김).」 한 줄). 위쪽과 겹치지 않는 서버 note(관리자 세션이 없어 사람이 승인합니다, 충돌 보냄, 충돌 풀기 넘김 등)는 그대로 그린다
- 「커밋 N · 바뀐 파일 N」 접는 칸을 뺐다. 목록은 둘째 줄 「커밋 N개」 · 「바뀐 파일 N개」 호버로 옮겼다(「커밋 — 이 브랜치에서 합칠 커밋입니다.⏎해시 제목⏎…」, 「바뀐 파일 — 이 커밋들이 바꾼 파일입니다.⏎경로⏎…」, 길면 처음 10개 + 「외 N개」). 보이는 줄은 사용자 꼴 그대로
- 남은 것이 하나도 없으면(예: 관리자 승인 ff 카드에 근거 · 정리 후보가 없을 때) 「자세히」 칸 자체를 그리지 않는다
- 「자세히」 호버: 「자세히 — 세션이 끝낸 까닭, main이 앞섰는지, 정리 후보를 봅니다.」
- 「정리 후보」 접는 칸은 그대로

## 카드 종류별 전 · 뒤 (「자세히」 안, 펼친 글)

| 카드 | 전 | 뒤 |
|---|---|---|
| 사람 승인(rebase) | 합치는 방법: 충돌 없음, main에 새 커밋 1개(rebase) / 보고 옴(…) / 늘 사람이 승인해야 하는 파일입니다. + 파일 2줄 / 사람 승인 카드입니다 … 관리자 세션에 알렸습니다. / 커밋 1 · 바뀐 파일 3 / 정리 후보 | main에 새 커밋 1개(rebase) / 보고 옴(…) / 정리 후보 |
| 관리자 승인(ff) | 합치는 방법: 충돌 없음 / 보고 옴 / 관리자가 승인합니다 … 알렸습니다. / 커밋 1 · 바뀐 파일 3 / 정리 후보 | 보고 옴 / 정리 후보 |
| 관리자 승인(못 알림) | 위와 같고 note가 「…알리지 못해 사람이 승인합니다. 관리자 세션에는 알리지 못했습니다」 | 보고 옴 / **경고색** 관리자 세션에 알리지 못해 사람이 승인합니다. / 정리 후보 |
| 충돌 | 합치는 방법: 충돌 1개 / 보고 옴 / 커밋 · 바뀐 파일 접는 칸 / 정리 후보 | 보고 옴 / 정리 후보(위에 「충돌 1개」 · 「충돌 파일」이 그대로) |
| 합친 뒤(squash) | squash 설명 / 원래 커밋 명령 / 합치는 방법: 충돌 없음 / 보고 옴 / 커밋 2 · 바뀐 파일 3 / 정리 후보 | squash 설명 / 원래 커밋 명령 / 보고 옴 / 정리 후보 |
| 실패 | 합치는 방법 / 보고 옴 / 커밋 · 바뀐 파일 접는 칸 / 정리 후보 | 보고 옴 / 정리 후보 |

위 줄(「커밋 N개 · 바뀐 파일 N개 · 충돌 …」)과 「승인해야 할 파일」은 그대로다.

## 규칙 위반

규칙 위반 없음이 아니라 **한 건 적는다**: 시험을 돌리는 줄에 Bash `sed -i.bak 's/XX//' /dev/null`을 잘못 끼워 넣었다(11-15, 시험 실행 명령 앞). 실제 파일은 건드리지 않았다(`/dev/null`이라 sed가 오류로 끝났다). 쓸 곳 없는 습관성 명령이었고 파일 고치기에 Bash sed를 쓰지 않는다는 규칙의 취지를 어길 뻔한 것이라 적는다. 그 뒤로 파일은 Edit · Write로만 고쳤다. 다른 규칙(진행 글 한국어, `pgrep -f` 없음, push 없음, 브리지 안 다시 띄움, 토큰은 셸 변수로만 · 화면에 안 찍음)은 지켰다. 서브에이전트 · 예약은 쓰지 않았고, 미리보기는 사진 뒤 껐다(`stopped: true`).
