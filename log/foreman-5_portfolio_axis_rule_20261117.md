# 포트폴리오 축 기준 문장 (코더 foreman-5, 11-17)

사용자 지시 22 답 7번. 포트폴리오 쓰기 지시문에 「보여줄 화면이 있으면 화면 축, 없으면 결정 중심」을 넣었다.

## 고친 지시문(`bridge/scribe_room.py` `task_prompt` portfolio 갈래)

전:
- 화면 축 하나만 있었다. 「편 목록을 정해」 앞에 「화면을 보고」가 붙었고, 한 편이 화면 하나, 화면 사진 필수, 「왜 · 버린 것 · 막힌 것은 노션 몫」이 무조건이었다.

후:
- 「축 고르기」 절을 맨 앞에 두었다. 기준 문장, 화면이 있는지는 서기가 저장소를 보고 정한다(화면 파일, UI 폴더, `tools/screen.py`로 찍을 화면), 고른 축과 본 근거를 `log/`에 적는다(`log/`가 없으면 마지막 응답에만).
- 「화면 축(보여줄 화면이 있을 때)」: 지금 규칙 그대로(한 편이 화면 하나, 「이 화면이 무엇을 해 주나」까지, 왜 · 버린 것 · 막힌 것은 노션 몫, 끝에 노션 링크).
- 「결정 중심(보여줄 화면이 없을 때)」: 편마다 상황, 고른 것, 까닭, 치른 값. 왜 · 버린 것 · 막힌 것이 본문이라 노션으로 미루지 않는다. 사진은 있으면, 코드 속 설명은 필요하면 노션 링크.
- 사진과 영상 절은 화면 축일 때 필수, 결정 중심은 넣는다면 같은 방식으로 바꿨다.
- 화면 전제 글을 두 갈래를 덮게 맞췄다: `TASKS` 설명, `scribe.js` 시키기 툴팁, 지시문 안의 「화면 축이 아닌 옛 편」을 「고른 축이 아닌 옛 편」으로.
