## 작업 중에 보낸 내 글이 대화에 안 뜨던 것 (11-05 사용자 보고)

- 경로 확인: 패널 입력 → 들어감(포먼 세션이 받았다, 두 번 보내 두 번 들어옴) → 트랜스크립트에는 `queue-operation enqueue` → `attachment queued_command`(delivered) — **새 턴이 아니라 열린 턴에 끼어든 입력** → DB에도 새 턴 없이 그 턴의 `queued` · `input` 이벤트 → WS로도 나갔다
- 끊긴 곳: 대화 API · 패널이 **턴의 첫 프롬프트만** 보여 줬다. CC가 일하는 중에 보낸 글은 턴이 되지 않으니 아예 안 보였다(탭 구조로 바꾼 것과 무관 — 처음부터). CC 답은 턴의 응답이라 보였다
- 고침: 대화 API가 턴마다 `queued`(op=delivered) 글을 함께 준다 → 패널이 프롬프트 다음에 "나 · 작업 중에 보냄"(내 말풍선)으로, 서브에이전트 결과 · 완료 알림은 "작업 중에 옴"(곁가지)으로. 대기열 글 저장 상한 500 → 2만 자(그 전 기록은 앞 500자). 보내면 · `queued` 이벤트가 오면 대화를 다시 읽는다
- 함께 찾은 것: 이 세션(포먼)이 작업 중에 쓴 짧은 진행 글이 영어로 나갔다 — CLAUDE.md "항상 한국어" 위반, 패널 화면으로 드러남
