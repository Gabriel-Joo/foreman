# 세션 번호를 크게, 제목을 작게 (11-15, 세션 430, 관리자 410 일감)

사용자: 사람과 관리자가 세션을 부를 때 쓰는 말은 번호라, 번호와 제목의 크기를 서로 바꾼다. 기능은 그대로, 보이는 것만.

## 한 일

번호와 제목이 함께 나오는 곳을 훑어 세 곳을 바꿨다. 두 글씨는 원래 둘 다 16px(본문 16px, `.small` 16px)이라 크기 값은 같고, 눈에 띄던 차이는 굵기와 색이었다. 그래서 전에 제목이 쓰던 값(굵게 · 본문색)을 번호에, 번호가 쓰던 값(작게 · 회색)을 제목에 줬다. 새 크기는 없고 글씨 배율(`--ui-zoom`)은 그대로 따른다(`.oside-main`의 zoom).

## 툴팁 첫 줄

패널의 「세션 N — FOREMAN 세션 번호입니다…」는 이미 번호가 앞이라 그대로. 「제목 — 이 세션이 지금 하는 일입니다…」의 「제목」은 세션 제목이라는 이 칸의 이름이라 그대로 두었다(번호 칸이 따로 있어 겹치지 않는다).

## 제목이 없을 때 · 길 때

- 제목이 없으면(`custom_title` · `title` · `cc_name` 모두 없음) 지금도 세션 해시(`short`)가 제목 자리에 나온다. 세션 345에서 번호 굵게 「세션 345」 아래 작은 회색 해시로 보인다. 어색하지 않다고 보고 로직은 안 바꿨다
- 호버는 이름이 「세션 N」 대신이면 둘째 줄을 뺀다
- 길 때 말줄임은 전과 같다(`.oside-bar.sess #pTitle`의 폭 전체 · `.oside-bar b`의 말줄임 규칙은 그대로)
