### 2. 승인 뒤 열린 화면의 막대
- **잰 방법**: 라이브 화면(:8000, `?probe=1`)을 헤드리스 크로미움으로 열고 CDP `Fetch`로 `/api/dashboard` 응답에 가짜 `merge_wait` 하나를 더했다가(승인 전) 뺐고(승인 뒤 — 서버가 바로 뺀 것과 같음), 그 세션 `/handoff`에 ready 카드를 넣었다. **합치기 POST는 서버에 보내지 않고 가짜 응답으로 끝냈다** — 실제 카드 · DB는 건드리지 않았다. 실제 단추 경로(#oMerge → 「세션」 탭 → [합치기] → 확인)를 누르고 POST 응답 시각부터 막대 숫자가 줄 때까지. 누르는 때는 주기 안에서 0~15초 무작위. 스크립트는 저장소에 넣지 않았다(일회용)
- **잰 값(고치기 전, :8000)**: 2.0 · 3.1 · 13.2 · 11.2초 — 0~15초에 고르게 퍼짐 = 15초 주기(`store.js RESNAP_MS`). 패널 `run()`은 패널 자료(`/handoff`)만 다시 받고 사무실 스냅샷은 안 받았다. 서버는 합치기 · 버리기 때 화면에 따로 WS 신호를 보내지 않는다
- 서버 쪽도 하나: `POST …/merge-prep`이 대시보드 캐시(2초)를 비우지 않았다 — 곧바로 받아도 2초 안이면 옛 값(카드 ready)을 받아 다시 15초를 기다릴 수 있었다(`/worktree`는 이미 비움)
- **고친 것**: `handoff.js run()` 끝에 `store.scheduleSnapshot(0)`(합치기 · 나중에 · 버리기 · 쉬게 하기 등 패널 동작 모두 — 막대 · 말풍선은 패널을 여는 길이라 승인은 늘 여기를 지난다), `bridge/api/handoff.py merge_prep_act`가 응답 전에 `dashboard.invalidate()`
- **잰 값(고친 뒤, 이 worktree 미리보기 :8200)**: 0.64 · 0.78 · 0.79 · 0.67초. (서버 캐시 비우기는 파이썬이라 미리보기에서는 안 돈다 — 잼은 응답을 가로채 바꿔서 캐시와 상관없음. 시험 `test_mergeprep.py test_api_off_and_on`이 승인 뒤 캐시가 비는지 본다)

## 설계와 달랐던 점 · 판단 근거
- **현장 테마 1024x700 넓게에서 말풍선이 캔버스 왼쪽 밖으로 잘렸는데 점검은 0건이었다**(「로 멈춤」만 보임). 인프라 방 왼쪽 끝 코더라 위 · 오른쪽 자리는 이웃 말풍선 · 이름표와 겹치고, 왼쪽 자리는 이름표와 안 겹쳐 「겹침 0」으로 뽑혔다 — `placeBubble`이 화면 밖을 몰랐고 `bubbleAudit`(겹침만 셈)도 못 잡았다. 그래서 화면 밖 넓이를 겹침으로 센다. 처음엔 모든 말풍선에 셌다가 방 화면에서 **다른 방(화면 밖) 말풍선**이 전부 걸려 「캐릭터가 화면 안일 때만」으로 좁혔다. 이제 현장은 발밑, 오피스는 왼쪽 안쪽에 놓인다. 다른 말풍선(서기 할 일 · 맡길 일 등)에도 같은 규칙이 걸린다 — 화면 밖으로 잘리던 경우만 달라진다
- **글자 수 시험은 뺐다**: 「API 오류로 멈춤」은 10자로 「사용자에게 보고함」(9자)보다 길지만 영문이 좁아 그린 폭이 문제였다 — 폭은 `bubbleAudit` · 사진으로
- **다시 알림을 `human_wait.py`에 둔 까닭**: 「살아 있고 · T 아니고 · 일하지 않는 세션만 · 30분 · DB rule 키 한 번」이 권한 거부 알림과 똑같다. 새 감시(새 작업 · main.py 배선)를 만들지 않았다. 30분도 같은 값 — 사람이 첫 알림을 보고 손댈 틈이고 알림 리듬이 하나가 된다
- **곧바로 다시 받기를 `run()` 하나에**: 일감은 「패널 [합치기] · 막대 · 말풍선 모두」인데, 막대 · 말풍선은 패널 「세션」 탭을 여는 길이고 승인은 늘 패널 [합치기](`run('합치기 승인', …)`)를 지난다. 그래서 `run()` 끝 한 곳에 두어 나중에 · 버리기 · 쉬게 하기도 함께 빨라진다
- **겹침 순서**: API 오류를 권한 거부 다음에 둔 것은 둘 다 막힘이고 권한 거부가 먼저 있던 순서라서, 답 기다림 위에 둔 것은 묻는 말이 오류 전 응답일 수 있어서(지금 막힌 까닭은 오류)
- 맡지 않은 파일(`coder.js` · `reconcile.py` · `overlap.py` · `mergeprep.py`)은 안 고쳤다. `coder.js`의 코더 할 일 목록(권한 거부 줄이 있는 곳)에는 API 오류 줄이 없다 — 필요하면 그 파일을 맡은 쪽에서
- 스키마 · `config/*.toml` · CLAUDE.md · README · docs는 안 고쳤다
